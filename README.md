# Cognetix_ProductLandingPage
# 🚀 NOVA – Smart Productivity Hub

A modern, responsive product landing page designed to showcase **NOVA**, a fictional smart productivity solution that helps users organize tasks, plan their day, and improve focus.

This project was developed as **Task 3 – Product Landing Page** of the Full Stack Developer Internship at **Cognetix Technology**.

## 📌 Project Overview

The NOVA Product Landing Page presents a clean, professional, and user-friendly interface for a modern productivity product. It highlights the product's features, benefits, workflow, and illustrative testimonials through an attractive and responsive design.

The project demonstrates frontend development skills using HTML, CSS, and JavaScript.

## ✨ Features

- **Responsive Design:** Works across desktop, tablet, and mobile devices.
- **Modern Hero Section:** Includes a compelling headline, product description, and call-to-action buttons.
- **Navigation Bar:** Provides easy navigation between website sections.
- **Product Features:** Showcases smart task management, daily planning, focus mode, and progress tracking.
- **Benefits Section:** Explains the advantages of using the product.
- **How It Works:** Presents the product workflow in three simple steps.
- **Testimonials:** Displays illustrative sample testimonials.
- **Call-to-Action Section:** Encourages visitors to explore or get started.
- **Interactive Elements:** Uses JavaScript to support website interactions.
- **Mobile Navigation:** Provides navigation suitable for smaller screens.
- **Accessible Interface:** Includes semantic HTML and keyboard-friendly controls.
- **Smooth Interactions:** Uses appropriate hover effects and animations.
- **Clean Layout:** Features modern typography, cards, spacing, and visual hierarchy.

## 🚀 Getting Started

### Prerequisites

Install the following tools:

- [Visual Studio Code](https://code.visualstudio.com/)
- A modern web browser, such as Chrome or Edge
- Live Server extension for VS Code (recommended)
- Git (optional, for version control)

### Installation

**1. Clone the repository**

```bash
git clone https://github.com/Tejaswini-2006/Cognetix_ProductLandingPage.git
```

**2. Navigate to the project directory**

```bash
cd Cognetix_ProductLandingPage
```

**3. Open the project in Visual Studio Code**

```bash
code .
```

Alternatively, open the folder manually in VS Code.

**4. Run the website**

- Open `index.html`.
- Right-click inside the editor.
- Select **Open with Live Server**.
- View the website in your browser.

You can also open `index.html` directly in a browser if the project does not require a local server.

## 📱 Responsive Design

The website uses CSS media queries and flexible layouts to adapt to different screen sizes.

- **Desktop:** Spacious layouts and prominent product presentation.
- **Tablet:** Adjusted content widths and card layouts.
- **Mobile:** Compact spacing, stacked sections, and mobile-friendly navigation.

The design aims to provide a consistent browsing experience across different devices.

## ♿ Accessibility

The project aims to follow basic accessibility practices, including:

- Semantic HTML elements
- Appropriate heading hierarchy
- Accessible navigation and controls
- Visible keyboard focus indicators
- Readable text and sufficient color contrast
- Support for reduced-motion preferences

## 🌐 Deployment

This is a static frontend project and can be hosted using GitHub Pages or another static website hosting service.

To deploy with GitHub Pages:

1. Push the project to a public GitHub repository.
2. Open the repository's **Settings**.
3. Navigate to **Pages**.
4. Select the `main` branch and root directory.
5. Save the configuration.
6. Wait for the deployment to complete.
7. Open the published URL and test the website.
